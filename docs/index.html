Method Notes

GoalBench reports separate Codex /goal runs on ProgramBench tasks; these are not official mini-SWE-agent leaderboard submissions. Resolved means ProgramBench's filtered behavioral pass rate is exactly 100%, and almost resolved means at least 95%.

The headline run is the closest GoalBench parity attempt: GPT-5.5 xhigh, strict no-internet enforcement, wrapper-only black-box target access, and a shorter mini-SWE-style prompt. The stricter no-internet scaffold adds an explicit behavior-audit prompt; no-internet-local-tools is a coming non-comparable ablation with local binary-analysis tools allowed.

The public table is scoped to the latest published result set. Cost is estimated from Codex token logs, not billing. See Task Details and the runbook for scoring, evidence, egress, and setup details. Sources: ProgramBench extended results and GPT 5.5 xhigh run detail.
